# Upload to GitHub

1. Download and extract the ZIP.
2. Visit https://github.com/Qaisar256/HydroGraph-FL (create the repository if needed).
3. Upload the **contents** of the extracted HydroGraph-FL_GitHub_Complete directory, preserving folder structure.
4. Or run `git init && git add . && git commit -m "HydroGraph-FL research project" && git branch -M main && git remote add origin https://github.com/Qaisar256/HydroGraph-FL.git && git push -u origin main`.
5. Check `DATA_PROVENANCE.md` and CSV reuse permissions before publishing.
6. Run tests, check outputs and cite model-specific experimental results only.
